Importer sans perdre la trace.

Un journal par compte. Les réimports identiques sont ignorés ; les conflits annulent tout l’import.

Choisir un fichier

Transactions déjà fermées, pas des fills bruts. CSV, JSONL ou liste JSON · 8 Mo maximum.

Associer les colonnes

PnL net : les frais ne seront pas soustraits une seconde fois. PnL brut : une colonne de frais est obligatoire.

Le contrat de données

01

Identifiant stable

Un identifiant unique par transaction fermée évite de compter deux fois le même résultat.

02

Date avec fuseau

Exemple : 2026-10-01T15:00:00Z. Les dates ambiguës sont refusées.

03

Montants explicites

USD, deux décimales maximum, sans séparateur de milliers. Net, ou brut et frais positifs.

Un export Tradovate ou Hermes peut nécessiter une transformation. Aucun format broker brut n’est déclaré compatible sans validation.

    Conventions importantes
    Les séances sont déduites à 18 h America/New_York, sauf colonne session_date fournie. Les jours fériés et les heures limites ne sont pas validés. Le replay ne simule pas les conditions de payout ni le cushion de cohérence. Le Sharpe n’est pas affiché : il nécessite une série de rendements et des conventions supplémentaires.
    La version Connect expose une API authentifiée et des outils MCP. Sur Railway, les données doivent résider sur un volume persistant dédié. Les connexions distantes doivent être prouvées par des sondes ; la présence du code ne suffit pas.
